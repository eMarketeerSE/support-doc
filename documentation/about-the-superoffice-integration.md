# About the SuperOffice integration

The eMarketeer–SuperOffice integration lets marketers pass business opportunities, leads, and intelligence to the sales team.

It connects your eMarketeer account to SuperOffice so data flows between the two systems and SuperOffice users see eMarketeer activity inside the CRM.

## Supported versions

eMarketeer supports SuperOffice Sales and SuperOffice Complete CRM.

## Connecting eMarketeer with SuperOffice

Connecting to SuperOffice Online is straightforward because both sides are prepared for it. [Use this guide to get started](/documentation/superoffice-online-integration/).

Connecting to on-premise installations is also straightforward when everything is in place. Some installations are shielded from the outside and need to be configured for remote communication before installation can proceed. [Use this guide to get started with on-premise](/documentation/on-premise-installation-process/).

## Integration parts

All versions of the integration include the following parts:

- Reading and writing data in SuperOffice.
- Addition of fields, web panels, and other elements to the SuperOffice client. [Read more](/documentation/actions-performed-during-set-up/).
