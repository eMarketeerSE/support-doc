# Whitelist of countries supporting SMS Sender ID

## SMS Sender ID whitelist

Sender IDs are not fully supported around the world. In some countries, like Belgium and the United States, not all mobile phone operators support sender ID. In order to ensure that all your recipients can receive your text messages, we are dynamically enabling sender ID based on the country of the recipient.

We would prefer to use sender ID for all operators in the world that support it, and phone number for the rest, but it is unfortunately not possible to correlate phone numbers to operators. Please contact us if you would prefer to use sender ID even in those cases where we cannot guarantee that the message can be sent with it, and we can provide a solution for you.

We expect the list of fully supported countries to grow over time, as well as change in some cases (e.g. when a new operator without sender id capabilities establishes themselves in countries).

The countries listed below are enabled to use alpha numeric Sender ID when sending from eMarketeer.

All other countries will show a mobile number (+46 76 686 22 48) as sender.
