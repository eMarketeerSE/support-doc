# Release notes — March 28, 2022

This release adds a clone block in the email editor and expands the types of campaign fields available.

## New and updated features

### Clone block in the email editor

You can now copy any type of content block when building an email. Hover over the block you want to copy, click the duplicate icon, and an exact copy of the block is pasted in your email.

![Clone block in the email editor](../.gitbook/assets/clone_block_email_editor-1.png)

### More types of campaign fields

With campaign fields, you can update your campaign in one place and have the change reflected across all components. This release adds more field types. The complete list is:

* Text — for headlines or other short snippets
* Text area — for longer text, like summaries
* Rich text — customize your text with bold, italics, and other style options
* Date and time
* Images
* Droplist
* Date and time of latest update in campaign fields is available in the API

### Sort campaign fields with drag-and-drop and field descriptions

As you add more campaign fields, it can get harder to keep an overview. You can now sort your list of campaign fields with drag-and-drop and add a short field description so you can find the field you are looking for.

See [Tutorial: how to use campaign fields](how%20to%20use%20campaign%20fields/).
