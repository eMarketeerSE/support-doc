# API (nytt)

eMarketeers API ger dig programmatisk åtkomst till data i ditt konto.

Referensdokumentation för API-funktionerna finns i API-portalen.

[https://api-doc.emarketeer.com/](https://api-doc.emarketeer.com/)

Du genererar din API-nyckel inne i eMarketeer-applikationen under **Settings** → **Plugins and integration**.
