# Contact field character limit

Each contact field has a character limit. Data that exceeds the limit is truncated. The table below shows the limit for each field.

<table><tbody><tr><td><strong>Contact field</strong></td><td><strong>Character limit</strong></td></tr><tr><td>firstname</td><td>500</td></tr><tr><td>lastname</td><td>500</td></tr><tr><td>salutation</td><td>500</td></tr><tr><td>email</td><td>500</td></tr><tr><td>company</td><td>500</td></tr><tr><td>address1</td><td>500</td></tr><tr><td>address2</td><td>500</td></tr><tr><td>zip</td><td>25</td></tr><tr><td>city</td><td>500</td></tr><tr><td>fax</td><td>500</td></tr><tr><td>mobile</td><td>100</td></tr><tr><td>telephone</td><td>500</td></tr><tr><td>state</td><td>500</td></tr><tr><td>country</td><td>500</td></tr><tr><td>title</td><td>500</td></tr><tr><td>external_id</td><td>500</td></tr><tr><td>note</td><td>65535</td></tr><tr><td>Custom*</td><td>2000</td></tr></tbody></table>

\* Any custom field (regardless of type) has a limit of 2000 characters.
