# Vad händer när jag når min kontaktgräns?

### Vad händer vid kontaktgränsen

När du når gränsen för kontaktdatabasen kan du inte skapa nya kontakter i kontot. Nya formulärinskick avvisas, filimporter listar kontakter som avvisade, och publicerade formulär stängs och visar ett felmeddelande.

### Så vet du att du närmar dig gränsen

För att undvika att kontot pausas skickar vi varningar när du närmar dig gränsen. Den första varningen går ut vid 90 % av kapaciteten. Varningarna når användarna på ditt konto via e-post och som chattmeddelanden inuti eMarketeer.

### Så skapar du nya kontakter igen

Få kontot tillbaka under gränsen genom att ta bort kontakter eller uppgradera planen. Läs om hur du hittar kontakter att ta bort i [Så här rensar du dina kontakter](clean-up-contacts.md). Kontakta oss via chatten i eMarketeer eller [via e-post](mailto:customerservice@emarketeer.com) om du vill uppgradera.

{% hint style="info" %}
När kontot är under gränsen igen tar det några minuter innan ändringen registreras och formulär och filimporter fungerar igen. För formulär som är inbäddade på din egen webbplats kan webbplatsens cache fördröja detta ytterligare.
{% endhint %}
