# Update Contact Card

The Update Contact Card step updates a field on the contact card.

<div data-with-frame="true" align="left"><img src="../../.gitbook/assets/journey-step-update-contact-card-settings.png" alt="Update Contact Card dialog with a checkbox field chosen and its value ticked"></div>

## Settings

* **Select field on contact card to update** — choose the field.
* **Set value on contact card** — set the value the field gets. How you set it depends on the field, for example a checkbox for a checkbox field.

Click **Apply** to save the step.
