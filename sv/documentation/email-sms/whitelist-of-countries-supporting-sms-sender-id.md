# Whitelist över länder som stödjer SMS Sender ID

Den här artikeln listar de länder där eMarketeer kan skicka SMS med alfanumeriskt Sender ID.

Stödet för Sender ID varierar mellan länder och operatörer. Använd den här listan för att bekräfta om dina mottagare ser ditt Sender ID eller ett reservtelefonnummer.

## Whitelist för SMS Sender ID

Sender ID stöds inte i hela världen. I vissa länder, som Belgien och USA, stödjer inte alla mobiloperatörer Sender ID. För att säkerställa att dina mottagare kan ta emot dina textmeddelanden aktiverar eMarketeer Sender ID dynamiskt baserat på mottagarens land.

Vi skulle helst använda Sender ID för varje operatör som stödjer det och falla tillbaka på ett telefonnummer för resten, men det är inte möjligt att korrelera telefonnummer med operatörer. Kontakta oss om du vill använda Sender ID i länder där vi inte kan garantera leverans med det, så kan vi erbjuda en lösning.

Listan över fullt stödda länder förväntas växa och förändras över tid, till exempel när en ny operatör utan stöd för Sender ID etablerar sig i ett land.

Länderna nedan har stöd för att använda ett alfanumeriskt Sender ID när du skickar från eMarketeer. Alla andra länder ser ett mobilnummer (+46 76 686 22 48) som avsändare.
