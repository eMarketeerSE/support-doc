# SuperOffice

## Supported versions

eMarketeer supports SuperOffice Sales and SuperOffice Complete CRM.

## Connecting eMarketeer with SuperOffice

Connecting to SuperOffice Online is straightforward because everything is prepared on both ends. [Use this guide to get started](superoffice-online-integration.md).

Connecting to on-premise installations is also straightforward when the prerequisites are in place. Some installations are shielded from external access and need to be configured for remote communication before you can proceed. [Use this guide to get started with on-premise](on-premise.md).

## Integration parts

All versions of the integration include:

* Reading and writing data in SuperOffice.
* Adding fields, web panels, and other items to the SuperOffice client. [Read more](actions-performed-during-set-up.md).
