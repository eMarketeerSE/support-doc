# Add / Remove tags

The Add / Remove tags step adds tags to the contact, or removes tags from the contact.

<div data-with-frame="true" align="left"><img src="../../.gitbook/assets/journey-step-add-remove-tags-settings.png" alt="Tags dialog with Add tags selected and the tags Denmark and Event chosen"></div>

## Settings

* Choose **Add tags** or **Remove tags**.
* **Select tags to add to, or remove from contact card** — select one or more tags.

Click **Apply** to save the step.

To learn more about tags, see [Tags](../../knowledge-base/contacts-lists/tags.md).
