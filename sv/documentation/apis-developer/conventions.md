# Konventioner

Kod skrivs med teckensnitt med fast bredd. Kursiv stil beskriver hur eMarketeer använder en specifik funktion. DCL är ett programmeringsspråk, så du bör vara bekant med allmänna termer som funktion, argument, värde och sträng.

### Termer

Termerna du behöver förstå för att läsa den här manualen:

- **DCL:** Dynamic Content Language, namnet på det här programmeringsspråket.
- **DCE:** Dynamic Content Engine, mallmotorn som används med DCL.
- **Page:** Innehållet där du tillämpar DCL. Detta kan vara ett e-postmeddelande, en webbsida eller ett SMS.
