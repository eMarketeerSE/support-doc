# Automatiska UTM-länkar

eMarketeer lägger till UTM-parametrar i länkarna i dina mejl och landningssidor, så att eMarketeer Web Tracker och verktyg som Google Analytics kan attribuera trafiken.

Det här är de UTM-parametrar som läggs till i dina länkar:

- `utm_source` — alltid "eMarketeer", för att ange vilken plattform besöket kom från.
- `utm_campaign` — namnet på den eMarketeer-kampanj som innehåller mejlet eller landningssidan.
- `utm_medium`
  - "email" för mejl.
  - "referral" för landningssidor.
- `utm_content`
  - Ämnesraden för mejl.
  - Sidtiteln för landningssidor.
- `utm_em_source` — specifikt för eMarketeer: ID:t för den komponent som används.
