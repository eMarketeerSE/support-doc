# SuperOffice integration

The eMarketeer–SuperOffice integration lets marketers send business opportunities, leads, and intelligence to the sales team.

### Supported versions

eMarketeer supports _SuperOffice Sales_ and _SuperOffice Complete CRM_.

### Connecting eMarketeer with SuperOffice

Connecting to **SuperOffice Online** is straightforward — everything is prepared on both ends. [Use this guide to get started](/documentation/superoffice-online-integration/).

Connecting to **on-premise installations** is also straightforward if everything is in place. Some installations are shielded from the outside and need to be configured for remote communication before installation can proceed. [Use this guide to get started with on-premise](/documentation/on-premise-installation-process/).

### Integration parts

All versions of the integration include the following parts:

- Reading and writing data in SuperOffice.
- Adding fields, web panels, and similar elements to the SuperOffice client. [Read more](/documentation/actions-performed-during-set-up/).
