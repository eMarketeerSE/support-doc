# DCL-introduktion

Det är inte ett fullständigt programmeringsspråk som C, PHP eller Visual Basic. Tänk på det som ett språk för att generera dynamiskt innehåll i dina e-postmeddelanden, SMS eller webbsidor. DCL saknar aritmetiska instruktioner men erbjuder viss flödeskontroll. Det är tätt kopplat till en mallmotor för HTML-webbsidor: Dynamic Content Engine (DCE).
