# Marknadsföringsresultat

Marknadsföringsresultat samlar din webbtrafik, ditt kampanjengagemang, dina konverteringar och dina leads i en vy, så att du ser vad som faktiskt driver din marknadsföring. Den ersätter den tidigare **Home**-sektionen och är den startvy du möter när du öppnar eMarketeer.

De flesta team arbetar över många kanaler, kampanjer och aktiviteter, och svaret på vad som fungerar ligger utspritt i separata rapporter. Den här översikten samlar de signalerna på ett ställe och besvarar en enda fråga: vad är det egentligen som driver min marknadsföring?

## Det här kan du använda den till

* Se vilka kanaler och kampanjer som ger kvalificerade leads.
* Jämför konverteringar och MQL mot tidigare perioder.
* Följ hela tratten från MQL via SQL och Opportunities till Won.
* Upptäck vilka nya MQL som hamnar på din Lead Board.
* Bedöm vad du ska satsa på härnäst, utifrån vad som redan presterar.

## KPI-rutorna

En rad rutor högst upp sammanfattar dina utgående aktiviteter och hur kontakter rör sig mot att bli kvalificerade leads.

| Ruta | Vad den räknar |
| --- | --- |
| Utgående | Utgående aktivitet som skickas från eMarketeer, till exempel e-post. |
| Engagerad | Kontakter som engagerade sig i din utgående aktivitet. |
| Konverterad | Leads som konverterat via formulär och andra ingångar. |
| Berikad | Kontakter vars profiler fått mer data. |
| Vårdad | Kontakter som förs framåt genom nurturing. |
| Kvalificerade leads | Kontakter som nått status som kvalificerad lead. |

## Widgetarna

Under rutorna fokuserar varje widget på en del av prestandabilden.

**Traffic Source over time** ritar upp webbtrafiken över den valda perioden, så att du ser trender och effekten av kampanjer medan de pågår.

**Top Traffic Channels** rangordnar varifrån trafiken kommer — annonser, SEO, sociala medier, e-post med mera — så att du ser vilka kanaler som bär mest volym.

**New Conversions** visar konverteringarna under perioden, med en jämförelse mot föregående period så att du ser om trenden pekar upp eller ner.

**Total MQLs Created** räknar de marketing qualified leads som genererats under perioden, även det jämfört med föregående period.

**What's Driving Performance** lyfter fram de kampanjer, annonser och formulär som bidrar mest, så att du ser vad som gör det tunga arbetet.

**Lead Source for MQLs** bryter ner, som andel av helheten, var dina MQL har sitt ursprung.

**Top Converters** listar de tillgångar som konverterar bäst, så att du kan satsa mer på det som fungerar.

**Lead Board Funnel** visar hela tratten från MQL till SQL till Opportunities till Won, så att du ser hur leads rör sig mot intäkt.

**Latest MQL on Leadboard** visar de senaste marketing qualified leads som lagts till på din Lead Board.

## Krav

För att se data i den här översikten behöver du Web Tracker installerad på din webbplats. Om du inte har satt upp den ännu, se [Installera Web Tracker-skriptet på din webbplats](../../documentation/web-tracker/installing-the-web-tracker-script-on-your-website.md).

Formulären och formulärskriptet matar också översikten. Installera formulärskriptet och använd formulär för att få hela bilden.
