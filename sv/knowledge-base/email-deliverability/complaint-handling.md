# Hantering av e-postklagomål

Den här artikeln förklarar hur eMarketeer hanterar e-postklagomål och vad du kan göra för att minimera dem.

Klagomål påverkar leveransbarhet och avsändarrykte. Att förstå hur de hanteras hjälper dig att skydda båda.

## Vad det innebär

Vissa e-postleverantörer (ESP) låter mottagare rapportera marknadsföringsmejl som skräppost eller oönskade. När en mottagare gör det skickar ESP:n en klagomålsrapport tillbaka till avsändarplattformen.

eMarketeer tar automatiskt emot klagomålsrapporter från ESP:er som stöder den här funktionen. När ett klagomål tas emot avregistreras den berörda kontakten automatiskt från framtida utskick.

## Varför det spelar roll

- Höga klagomålsfrekvenser påverkar e-postens leveransbarhet negativt.
- Upprepade klagomål skadar ditt avsändarrykte hos brevlådeleverantörer.
- Om klagomålsfrekvenserna blir för höga kan e-postutskick blockeras tillfälligt eller permanent för ditt konto, vilket innebär att inga e-postmeddelanden kan skickas.

Automatisk klagomålshantering skyddar både dig och eMarketeer, men den kan inte kompensera för dåliga utskicksrutiner.

## Vad du bör göra

För att minimera klagomål och undvika begränsningar i utskick, följ best practices för e-postmarknadsföring:

- Skicka endast till mottagare som uttryckligen har valt att prenumerera.
- Gör avregistreringslänkar lätta att hitta och använda.
- Håll innehållet relevant, förväntat och konsekvent.
- Undvik plötsliga eller stora ökningar i utskicksvolym.
- Identifiera dig tydligt som avsändare.

För detaljerad vägledning, se [Maximera framgång med e-postmarknadsföring – best practices och fallgropar att undvika](https://support.emarketeer.com/knowledgebase/maximizing-email-marketing-success-best-practices-and-pitfalls-to-avoid/).
