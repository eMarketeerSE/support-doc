# Send SMS / Text message

The Send SMS / Text message step sends a text message to the contact. The SMS must already exist in a campaign: you can't create a new SMS from inside a Journey.

## Choose the SMS

When you add the step, a list of your text messages opens. It shows each message's name, the campaign it belongs to and when it was created. Search by name if the list is long, and click the SMS you want.

<div data-with-frame="true" align="left"><img src="../../.gitbook/assets/journey-step-send-sms-sms-list.png" alt="Send SMS dialog with a search field and a list of text messages with name, campaign name and created date"></div>

## Settings

After you choose an SMS, the step shows its name, the sender and a preview of the message. To pick a different message, click **Choose other sms**.

<div data-with-frame="true" align="left"><img src="../../.gitbook/assets/journey-step-send-sms-sms-settings.png" alt="Send SMS dialog with the name of the chosen SMS, the sender and a preview of the message"></div>

Click **Apply** to save the step.

## Good to know

* You can add the step before the SMS is ready, as a placeholder. A Journey with unfinished steps can be saved, but not activated.
* The report for the SMS is in the campaign where you built it.
