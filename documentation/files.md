# Files

The Files area is where eMarketeer stores every file you use — images for emails and forms, documents, media, and web documents. You can open it from the main navigation, and reach the same files from within the component editors while you build.

## The five default folders

The Files area always contains these five folders. You cannot delete or move them:

* **My_Images** — the default location for image uploads.
* **My_Documents** — documents.
* **My_Media** — media files.
* **My_Webdocs** — web documents.
* **_edited_images** — every image you resize or edit in the image editor is saved here, while the original is preserved in its own folder.

Alongside these, you can create your own folders, and add, move, or delete files and folders to organize your library.

## Supported file formats

You can upload files with these extensions:

`jpg`, `jpeg`, `png`, `gif`, `pdf`, `doc`, `xls`, `ppt`, `docx`, `xlsx`, `pptx`, `css`, `eot`, `ttf`, `otf`, `woff`, `svg`, `js`, `html`, `ics`, `woff2`

The maximum size for a single file is 50 MB.

{% hint style="info" %}
Video files are best hosted on a dedicated video streaming service and embedded into your content. The email and page component editors include built-in video embed blocks.
{% endhint %}

## File paths and moving files

Each file has an absolute path that points to its exact location in the Files area. When you use a file — an image in an email or form, for example — that use depends on the path.

Moving a file to another folder changes its path. This can break the places where the file is already used, leaving a missing image or a broken link. Move files with care once they are in use, and check anything that references them afterward.

## Working from the component editors

The Files area is also available directly inside the component editors. When you add or replace an image or document while building an email or page, you browse the same folders and files — so everything stays in one place.
