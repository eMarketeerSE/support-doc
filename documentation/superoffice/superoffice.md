# SuperOffice Integration

The eMarketeer–SuperOffice integration lets marketing teams send business opportunities, leads, and intelligence to sales.

## Supported versions

eMarketeer supports SuperOffice Sales and SuperOffice Complete CRM.

## Connecting eMarketeer with SuperOffice

Connecting to SuperOffice Online is straightforward because everything is prepared on both ends. [Use this guide to get started](/documentation/superoffice-online-integration/).

Connecting to on-premise installations is also straightforward when the prerequisites are in place. Some installations are shielded from external access and need to be configured for remote communication before you can proceed. [Use this guide to get started with on-premise](/documentation/on-premise-installation-process/).

## Integration parts

All versions of the integration include:

- Reading and writing data in SuperOffice.
- Adding fields, web panels, and other items to the SuperOffice client. [Read more](/documentation/actions-performed-during-set-up/).
