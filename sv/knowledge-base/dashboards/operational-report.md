# Operational Report

Operational Report ger dig en snabb överblick över vad som händer i ditt konto just nu. Den samlar dina senaste utskick, formulärinskickningar, kampanjer, Journeys och nyligen skapat arbete på en enda skärm, så att du ser pågående aktivitet utan att öppna varje rapport för sig.

Använd den som din startpunkt: kolla vad som precis gått ut och vad som är schemalagt härnäst, se vad besökare skickar in, håll koll på vilka kampanjer och Journeys som är aktiva, och följ hur webbengagemanget hänger ihop med dina e-postutskick. Komponent- och kontaktnamn i rapporten är länkar — klicka på dem för att öppna komponentrapporten eller kontaktkortet.

## Det här kan du använda den till

* Se pågående arbete i hela kontot på ett ställe — utskick, formulär, kampanjer, Journeys och nyligen skapade komponenter.
* Gå direkt till detaljerna: komponent- och kontaktnamn länkar till komponentrapporten eller kontaktkortet.
* Korrelera webbengagemang med dina e-postutskick för att se hur trafiken svarar på det du skickar.
* Kontrollera vad som är schemalagt att gå ut härnäst, inte bara vad som redan skickats.
* Håll koll på vilka kampanjer och Journeys som är aktiva just nu.

## Widgetarna

De flesta widgetar visar alltid den senaste aktiviteten i ditt konto. Bara grafen Sendouts and Web Sessions högst upp påverkas av datumväljaren — de övriga widgetarna berörs inte av den.

**Sendouts and Web Sessions** är tidslinjen högst upp. Den ritar upp dina e-postutskick tillsammans med webbsessioner över den valda perioden, så att den fungerar både som kontots e-posttidslinje och som ett sätt att korrelera webbengagemang med det du skickar. Använd datumväljaren (uppe till höger) för att ändra perioden — det är den enda widget som datumintervallet påverkar. Under grafen markerar varje e-postikon och siffra de e-postmeddelanden som skickades det datumet; klicka på en för att se vilka e-postmeddelanden som gick ut den dagen och för att öppna en enskild komponentrapport.

**Recent Sendouts** listar de fem senaste utskicken via e-post och SMS med fler än 20 mottagare, med öppningsfrekvens, klick, CTR och CTOR. Växla till **Scheduled** för att i stället se de kommande utskicken närmast i tiden. Klicka på ett komponentnamn för att öppna dess komponentrapport.

**Latest Sendout** lyfter fram ditt allra senaste utskick, med en genväg till dess rapport.

**Latest form submits** visar de fem senaste formulärinskickningarna, inklusive formuläret och dess kampanj samt kontakten som skickade in. Klicka på en kontakt för att öppna kontaktkortet, eller öppna detaljerna för inskickningen.

**Active Campaigns** listar de kampanjer som har mest aktuellt engagemang, med klick, konverteringar och MQL. Klicka på en kampanj för att öppna dess rapport.

**Active Journeys** visar de senast triggade Journeys, med den senaste kontakten som rört sig igenom och antal kontakter som är i Journeyn och hur många som har slutfört den.

**Recent created work** listar de senast skapade komponenterna, med vem som skapade var och en och när, så att du kan ta vid där teamet slutade.

## Krav

Web Sessions-delen av grafen högst upp kräver att Web Tracker är installerad på din webbplats. Utan den visar grafen fortfarande dina utskick, men ingen webbsessionsdata. Se [Installera Web Tracker-skriptet på din webbplats](../../documentation/web-tracker/installing-the-web-tracker-script-on-your-website.md).
