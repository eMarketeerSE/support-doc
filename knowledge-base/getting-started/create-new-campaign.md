# How to create a new campaign

Create a campaign as the container for the emails, forms, and landing pages you want to send and publish.

A campaign groups related components, so creating one is usually the first step for a new piece of work in eMarketeer.

<div align="left" data-with-frame="true"><img src="../../.gitbook/assets/create-new-campaign-new-campaign-dialog.png" alt="New Campaign dialog with the Campaigns menu item, New Campaign button, Campaign name field and Create button numbered 1 to 4"></div>

{% stepper %}
{% step %}
### Open Campaigns in the left sidebar

If you want the new campaign to live inside an existing folder, navigate to that folder first.
{% endstep %}

{% step %}
### Click \[New Campaign] at the top-left
{% endstep %}

{% step %}
### Give the campaign a unique name

The name identifies the campaign inside eMarketeer and is never shown to your contacts. You can also add an optional description and tags. Both are internal-only.

{% hint style="info" %}
**Note:** The Campaign name is also used by the [web tracker](../../documentation/web-tracker/) to identify which campaign email traffic to your website originates from.
{% endhint %}
{% endstep %}

{% step %}
### Click \[Create] in the dialog

This creates the campaign and opens its empty Components page.
{% endstep %}
{% endstepper %}

## What to do next

Click \[Add Component] to add your first component to the campaign. This might be an email invitation, a registration form, or a landing page.

<div align="left" data-with-frame="true"><img src="../../.gitbook/assets/create-new-campaign-add-component-menu.png" alt="Add Component menu listing Email, Form, SMS, Landing Page and Mobile App"></div>

The following articles cover each component type from start to finish:

* [Creating your first email](basics-creating-email.md)
* [Creating your first form](basics-creating-form-new.md)
* [Creating your first SMS](basics-creating-sms.md)
* [Creating your first landing page](../developer-advanced/creating-first-webpage.md)

{% hint style="info" %}
Mobile apps are essentially landing page components but with a specialized template.
{% endhint %}
