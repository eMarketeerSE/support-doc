# Actions performed during SuperOffice Integration setup

**Note:** The actions on this page is performed automatically on SuperOffice versions 7.3 and newer. For older versions these steps needs to be performed manually.

When you integrate eMarketeer with SuperOffice, some actions are automatically performed on SuperOffice to enable eMarketeer features from within SuperOffice.

In summary, the following items are added.

-   Web panels
-   Fields
-   Types
-   Sources
-   Projects

#### Database Fields

eMarketeer creates new database fields in SuperOffice to provide sales and activites generated by eMarketeer with more information.

The created fields can be found in SuperOffice Admin in the “Fields” section under the “Sales” and “Follow-up” tabs.

Two fields called “eMarketeer:1” and “eMarketeer:2” are created under “Sales” and “Follow-up”. (4 fields in total)

All fields are created as “long text” with a length of 195.

#### Web panels

These items are found in SuperOffice Admin under “Lists” -> “Items” tab -> “GUI Web panel”. The panels loads information from eMarketeer.

**Lead Report**  
Name: Lead Report  
URL: https://app.emarketeer.com/ext/services/leadreport/?emid=YOUR-EMID  
Window Name: Event Details  
Visible in: Panel -> Web Panel  
Show: uncheck all  
Available check all

**Sales info**  
Name: eMarketeer detailed sales info.  
URL: https://app.emarketeer.com/ext/services/so\_index.php?f=<ss45>&e=<ss46>  
Window Name: e.g. Sale Event Details  
Visible in: Panel -> Sales card  
Show: uncheck all  
Available check all

**Activity info (Follow-up)**  
Name: eMarketeer detailed info.  
URL: https://app.emarketeer.com/ext/services/so\_index.php?f=<ts45>&e=<ts46>  
Window Name: e.g. Event Details  
Visible in: Dialog -> Dialog for follow-ups  
Show: uncheck all  
Available check all

**Timeline Report**  
Name: Timeline Report  
URL: \[url from eMarketeer\] (Replace the e-mail address with the SO variable <amai>)  
Window Name: e.g. Timeline Report  
Visible in: Panel -> Contact Dialog (SuperOffice 7.5 and later only. For earlier versions, select Navigator Panel.)  
Show: uncheck all  
Available check all

**Follow-up types**

These types are created to be used for activities generated by eMarketeer.

-   Web visit feed
-   Email feed
-   SMS/Text feed
-   Form feed
-   Landing page feed

**Sale Source**

A new sale source is created called “eMarketeer”.

#### Projects

A new project is created called “Web Visits” which will stor all contacts visiting your web site.

#### Troubleshooting

Once the fields and panels are created they may not work instantly. To make sure it all works, do the following.

-   Flush SuperOffice to make the panels show in the clients instantly.
-   Make sure the created fields are in a published state.

#### Uninstalling eMarketeer

eMarketeer does not remove panels or fields when disabling the integration. This needs to be done manually.
