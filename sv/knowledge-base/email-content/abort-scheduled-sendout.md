# Så avbryter du ett schemalagt utskick

Du kan stoppa ett schemalagt mejl eller SMS innan det skickas, från kampanjens flik **Event History**.

Den här guiden visar var du hittar alternativet för att avbryta, och hur du hittar de utskick du har schemalagt.

## Avbryt ett schemalagt utskick

<div data-with-frame="true" align="left"><img src="../../.gitbook/assets/abort-scheduled-sendout-event-history.png" alt="Kampanjens flik Event History med ett kommande schemalagt mejl och knapparna Delete All och Abort"></div>

1. Öppna kampanjen som innehåller det schemalagda mejlet eller SMS:et och klicka på fliken **Event History**.
2. Hitta utskicket under **Upcoming**. **When** visar när det skickas. **What** visar komponenten och vilka den går till, till exempel **Uploaded File 34**, så att du snabbt kan kontrollera vilka mottagare utskicket har.
3. Klicka på **Abort** för att stoppa utskicket. Om flera komponenter är schemalagda i kampanjen klickar du på **Delete All** för att avbryta alla.

När du avbryter tas bara schemaläggningen bort. Mejlet eller SMS:et finns kvar i kampanjen som det är, så du kan redigera det och schemalägga eller skicka det igen.

## Hitta dina schemalagda utskick

<div data-with-frame="true" align="left"><img src="../../.gitbook/assets/abort-scheduled-sendout-scheduled-widget.png" alt="Widgeten Recent Sendouts med fliken Scheduled vald, som listar två kommande e-postutskick"></div>

Om du inte minns vilken kampanj ett utskick hör till öppnar du **Dashboards** och går till [Operativ rapport](../dashboards/operational-report.md). Klicka på fliken **Scheduled** i widgeten **Recent Sendouts**. Där visas de 5 schemalagda mejl eller SMS som ligger närmast i tid, med kampanjens namn inom parentes efter varje utskick.
