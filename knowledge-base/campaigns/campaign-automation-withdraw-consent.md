# Withdraw consent automation

The Withdraw consent automation is a [campaign automation](campaign-automations.md) that withdraws the consent for marketing sendouts of the contact who triggered it.

<div data-with-frame="true" align="left"><img src="../../.gitbook/assets/campaign-automation-withdraw-consent-settings.png" alt="Withdraw consent automation settings with only the name and Do only once per contact"></div>

## Settings

* **Name** — a name for the automation, shown in the campaign's **Automation rules** list.
* **Do only once per contact** — selected by default, so the automation runs at most once for each contact.

The automation has no settings of its own besides the name.

## Trigger

Choose the component and event that run the automation under **When this happens**. See [Choose the trigger](campaign-automations.md#choose-the-trigger).
