# GDPR – General Data Protection Regulation

This page is the main resource on the General Data Protection Regulation (GDPR) for eMarketeer users.

<div data-with-frame="true"><img src="../../.gitbook/assets/600x315xgdpr-flag.png.pagespeed.ic.FWbONW9d6s.png" alt="GDPR text over an EU flag"></div>

The page is updated continuously until GDPR is in full effect on May 25th, 2018. eMarketeer has scheduled changes and updates that ship continuously before that date. The compliance project focuses on two areas:

1. Architectural changes that make eMarketeer a GDPR-compliant service provider for data storage. This includes a definition of sensitive data, extended logging, and the ability to show, forget, and transfer data as GDPR requires.
2. New and updated features that simplify the path to GDPR compliance. This includes form blocks for consent, extended subscription features, and more.

Return to this page for the latest progress on the GDPR compliance project.

For background, visit the official site for the [GDPR directives](https://www.eugdpr.org/eugdpr.org.html).
