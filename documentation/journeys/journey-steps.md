# Journey Steps

Journey steps are the actions a Journey runs for each contact who enters it. This page lists the basic steps and links to how each one is set up.

Journey steps are not the same as [campaign automations](../../knowledge-base/campaigns/campaign-automations.md), which run a single action when a contact interacts with a component in one campaign.

To add a step, click a dot on the line between two steps in the Journey builder. The **Add Journey step** panel opens, with the steps grouped as below. For a walkthrough of building a Journey, see [Creating your first Journey](creating-your-first-journey.md).

## Campaign Component

* **[Send Email](journey-step-send-email.md)** — send an email to the contact.
* **[Send SMS / Text message](journey-step-send-sms.md)** — send a text message to the contact.
* **[Notify stakeholder](journey-step-notify-stakeholder.md)** — alert a team member about the contact.

## Logic

* **[Wait for trigger](journey-step-wait-for-trigger.md)** — pause until the contact meets a set of conditions.
* **[Wait](journey-step-wait.md)** — pause for a set amount of time.
* **[If / Else](journey-step-if-else.md)** — branch the Journey on a condition.
* **[Start New Journey](journey-step-start-new-journey.md)** — add the contact to another Journey.

## Lead

* **[Create Lead (MQL)](journey-step-create-lead.md)** — create a marketing-qualified lead.
* **[Change Lead Stage](journey-step-change-lead-stage.md)** — move the lead to another stage.
* **[Delete Lead](journey-step-delete-lead.md)** — remove the lead from all Lead Streams.

## Contact

* **[Legal Basis](journey-step-legal-basis.md)** — set the legal basis for the contact.
* **[Update Subscription](journey-step-update-subscription.md)** — subscribe or unsubscribe the contact.
* **[Contact Category](journey-step-contact-category.md)** — change the contact category.
* **[Update Contact Card](journey-step-update-contact-card.md)** — update a field on the contact card.
* **[Contact List](journey-step-contact-list.md)** — add the contact to, or remove them from, a contact list.
* **[Add / Remove tags](journey-step-add-remove-tags.md)** — tag or untag the contact.
