# About the SuperOffice integration

The eMarketeer – SuperOffice integration lets marketeers send business opportunities, leads and intelligence to the sales team.

#### Supported versions

eMarketeer supports _SuperOffice Sales_ and _SuperOffice Complete CRM_.

#### Connecting eMarketeer with SuperOffice

Connecting to **SuperOffice Online** is a very simple since it’s all prepared in both ends.  
[Use this guide to get started](/documentation/superoffice-online-integration/).

Connecting to **on premise installations** is also easy if everything is in place. However some installations are shielded from the outside and needs to be configured for remote communication before installation can proceed.  
[Use this guide to get started with on premise](/documentation/on-premise-installation-process/).

#### Integration parts

All versions of the integration contains the following parts.

-   Reading and writing data in SuperOffice.
-   Addition of fields, web panels etc to the SuperOffice Client. [Read more](/documentation/actions-performed-during-set-up/).
