# GDPR – General Data Protection Regulation

![](../assets/gdpr-general-data-protection-regulation/600x315xgdpr-flag.png.pagespeed.ic.FWbONW9d6s.png)

#### **This page is the main resource regarding General Data Protection Regulation (GDPR) for eMarketeer users. The page will be updated continuously until GDPR is in full effect (May 25th, 2018).**

eMarketeer has scheduled several changes and updates that are to be released continuously before May 25th 2018. In short, the GDPR compliance project focuses on two different areas:

1.  **Architectural changes** that ensures eMarketeer as a GDPR compliant service provider for data storage. This includes definition of sensitive data, extended logging and the ability to show, forget and transfer data as required by GDPR.
2.  **New and updated features** to simplify the process to become GDPR compliant. This includes, for example, specific form blocks for consent, extended subscription features, etc.

_Return to this page to get the latest on the progress of the GDPR compliance project, as this page is updated continuously._

For more information, visit the official site for the [GDPR directives](https://www.eugdpr.org/eugdpr.org.html).
