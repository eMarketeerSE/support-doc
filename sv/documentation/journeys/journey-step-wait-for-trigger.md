# Wait for trigger

Steget Wait for trigger håller kvar kontakten i steget tills den uppfyller ett antal villkor. Sedan går kontakten vidare till nästa steg.

<div data-with-frame="true" align="left"><img src="../../.gitbook/assets/journey-step-wait-for-trigger-settings.png" alt="Dialogen Wait for trigger med ett villkor om att ett formulär skickats in och en tidsgräns på 3 dagar"></div>

## Inställningar

* **Conditions** — klicka på **Set conditions** för att välja vad kontakten måste göra eller matcha, till exempel skicka in ett formulär. Villkoren du anger visas i steget. Klicka på **Edit** för att ändra dem.
* **Set a time limit** — valfritt. Om kontakten inte uppfyller villkoren inom tidsgränsen går den ändå vidare till nästa steg. Ange ett tal och välj en enhet, till exempel timmar eller dagar.

Klicka på **Apply** för att spara steget.
