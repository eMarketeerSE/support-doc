# Start New Journey

Steget Start New Journey lägger till kontakten i en annan Journey.

<div data-with-frame="true" align="left"><img src="../../.gitbook/assets/journey-step-start-new-journey-settings.png" alt="Dialogen Start new Journey med ett fält för att välja Journey"></div>

## Inställningar

* **Journey** — välj den Journey som kontakten ska läggas till i, eller börja skriva för att söka efter den.

Klicka på **Apply** för att spara steget.
