# How to Create a New Contact List

This article is intended to guide you through how to create a New Contact List to use for your Campaign in just a few easy steps.

![](../assets/new-contact-list/pn_21-08-18_14-57-33.png)

Image of the Steps to Create a New Contact List

### Step-by-Step Guide

1.  Go to the main Contacts Page for the Account by clicking the **Contacts** button on the page banner
2.  Go to the **Contact List** page found on the Left Navigation bar of the Contacts Pages
3.  Click the **Add Contact List** button found above the list of Contact Lists on the Account
4.  Write a Name for your new Contact List and click the **ADD** button to create the new list

If you want to import contacts from Excel to your new Contact List then a guide for that can be found [here](https://support.emarketeer.com/knowledgebase/import-contacts-from-excel/).
