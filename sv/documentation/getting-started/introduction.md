# Introduktion

DCL är ett mallspråk som används för att personifiera innehåll i eMarketeer.

Det är inte ett fullständigt programmeringsspråk som C, PHP eller Visual Basic. Tänk på det som ett språk för att skriva ut dynamiskt innehåll i din e-post, SMS eller webbsidor. DCL erbjuder inga aritmetiska instruktioner, men ger viss flödeskontroll. Det är tätt kopplat till en mallmotor för HTML-webbsidor: Dynamic Content Engine (DCE).
