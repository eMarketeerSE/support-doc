# Product launch — October 2025

The October 2025 release introduces the Marketing Performance Dashboard, the first of several new dashboards in eMarketeer.

It gives you a single view of what is driving traffic, conversions, and leads.

## The Marketing Performance Dashboard

This dashboard is designed to give you clarity on what is working in your marketing. Instead of juggling different reports, you have one place to see:

* Outbound activity and nurturing (emails, engagements, captured leads, nurturing, qualified leads)
* Website traffic over time and by source (ads, SEO, social, email, and more)
* Conversions and MQLs compared to previous periods
* What campaigns, ads, and forms drive performance
* The full funnel view from MQL → SQL → Opportunities → Won
* Which new MQLs are added to your Lead Board

By combining website traffic data with the other data eMarketeer already captures, the dashboard becomes your performance hub. It helps you answer the question: what is really driving my marketing?

The new dashboard replaces the old Home section in eMarketeer.

## What you need to install

<div data-with-frame="true"><img src="../.gitbook/assets/26a0.svg" alt="Warning"></div> The dashboard requires the new web tracker script to be installed on your website. Without it, no website traffic data will show. [Read how to install the tracker here.](../documentation/the-web-tracker/)

The [new forms](../documentation/the-form-component/) and the new forms script also contribute to the data on the dashboard. If you have not installed the new forms script, install it and start using the new forms. [Read how to install the forms script here](../documentation/publish-a-form/).

## What is next

This is only the beginning. More dashboards are on the way, each designed to make it easier for you to prove the impact of your marketing and act on what works.

Log into eMarketeer to see the new Marketing Performance Dashboard in action.
