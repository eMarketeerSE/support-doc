# SuperOffice on-premise integration

Setting up the on-premise integration involves three steps: reviewing the requirements, configuring NetServer access, and enabling the connection from eMarketeer.

## Requirements overview

- SuperOffice version 7.5 or newer.
- NetServer running on IIS and exposed to eMarketeer over the internet.
- A dedicated SuperOffice user for the integration.

## Setup steps

1. [Installation process](on-premise-installation-process.md) — review requirements and what eMarketeer installs in SuperOffice during setup.
2. [NetServer URL and user creation](on-premise-netserver-url-and-user-creation.md) — expose NetServer to eMarketeer, find the WSDL URL, and create the integration user.
3. [Enabling the integration](on-premise-enabling-the-integration.md) — complete the final setup steps in eMarketeer.
