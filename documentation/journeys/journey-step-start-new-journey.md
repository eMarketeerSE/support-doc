# Start New Journey

The Start New Journey step adds the contact to another Journey.

<div data-with-frame="true" align="left"><img src="../../.gitbook/assets/journey-step-start-new-journey-settings.png" alt="Start new Journey dialog with a field to choose the Journey"></div>

## Settings

* **Journey** — choose the Journey to add the contact to, or start typing to search for it.

Click **Apply** to save the step.
